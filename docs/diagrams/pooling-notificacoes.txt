sequenceDiagram
    actor FE as Frontend (usuário logado)
    participant NC as NotificationController
    participant NS as NotificationService
    participant UN as UserNotificationRepository
    participant NR as NotificationRepository

    loop a cada 2 minutos (setInterval)
        FE->>NC: GET /api/notifications?unread=true
        NC->>NS: buscarNaoLidas(userId)
        NS->>UN: findByUserIdAndReadAtIsNull(userId)
        UN->>NR: join notifications (ordenado por created_at desc)
        NR-->>UN: linhas de user_notifications + notificação
        UN-->>NS: List<Notification>
        NS-->>NC: List<NotificationResponse>
        NC-->>FE: 200 OK

        alt existem não lidas
            FE->>FE: exibe toasts + badge de count
            FE->>NC: PATCH /api/notifications/{id}/read (ao abrir)
            NC->>NS: marcarLida(id, userId)
            NS->>UN: update read_at = now()
            UN-->>NS: ok
            NS-->>NC: 200 OK
            NC-->>FE: confirmado
        end
    end
